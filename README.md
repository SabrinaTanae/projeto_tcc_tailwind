## Comparativo de Frameworks CSS: Implementação com Tailwind CSS

Este projeto faz parte do meu Trabalho de Conclusão de Curso (TCC) em Sistemas para Internet no IFSP, onde realizei uma análise prática sobre a usabilidade, flexibilidade e previsibilidade de diferentes frameworks CSS.

## Sobre o Projeto
O objetivo desta aplicação foi validar a eficiência do **Tailwind CSS** na criação de interfaces modernas e responsivas. Através da abordagem de classes utilitárias, explorei a agilidade no desenvolvimento e a facilidade de customização do layout sem sair do arquivo HTML.

## Tecnologias Utilizadas
* **HTML5**: Estruturação semântica.
* **Tailwind CSS**: Estilização baseada em utilitários e design responsivo.
* **El-transition**: Biblioteca para facilitar a aplicação de transições e animações de entrada e saída.
* **GitHub Pages**: Hospedagem da aplicação.
